## 🟢 Nível: Iniciante

### 🐶 Calculadora de Idade Canina

Aplicação para calcular a idade de cães em anos humanos equivalentes, considerando porte e tempo de vida.

#### Versões do Projeto
* **Versão Simplificada:** Lógica básica de cálculo em HTML e JS.
* **Versão Dinâmica:** Interface reativa, animações em SVG, suporte a meses/anos e ajuste automático por porte de cão.
